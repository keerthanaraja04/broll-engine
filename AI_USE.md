# AI Use Declaration

This document declares how AI tools were used in the development of broll-engine.

---

## Development Assistance

This project was developed with assistance from **Kiro** (Amazon AI coding
assistant) within the Kiro IDE. Kiro acted as a pair-programming assistant:
it generated initial code scaffolding, suggested implementations, wrote
docstrings, and drafted test cases in response to detailed specifications
provided by the developer.

**All code was reviewed, modified, and accepted by the developer.** No code
was shipped without understanding its intent and verifying its correctness
against the project requirements.

## AI Models Used at Runtime

The system itself uses AI models as core components (not as development aids):

| Model | Provider | Purpose |
|-------|---------|---------|
| `whisper-large-v3` | Groq | Transcription of narration audio |
| `llama3-8b-8192` | Groq | Scene planning in JSON mode |
| `llava-v1.5-7b-4096-preview` | Groq | Clip relevance scoring against narration |
| `playai-tts` | Groq | Text-to-speech synthesis |
| `llava-v1.5-13b-4096-preview` | Groq | Independent evaluation of clip quality |

These models are accessed through the Groq API. No model weights are stored
or distributed as part of this repository.

---

## AI-Generated Content in Outputs

The generated videos contain:
- **Stock footage** from Pixabay (human-created, CC-licensed)
- **TTS audio** synthesised by Groq's `playai-tts` model
- **Subtitles** generated from Whisper word timestamps
- **Title cards** generated by FFmpeg (no AI model)

No AI-generated images are used. All footage is sourced from Pixabay, which
explicitly marks AI-generated content — the `is_ai_generated` field in
`timeline.json` records this for every clip. The system's licence gate
does not block AI-generated Pixabay content per se, but it is flagged and
visible to downstream consumers.

---

## Transparency

The system produces a `manifest.json` with every job that documents:
- Which model was used for each AI step
- The adapter implementation (`groq` or `mock`)
- Per-call cost estimates
- All warnings accumulated during processing

This makes every AI decision in the pipeline auditable.
